# Shipfulness

you have a ship that is way too long and a canal that is way too narrow. get to the end before the timer runs out, and try not to sink on the way.

the hull actually breaks where you hit it, so every crash leaves a hole. enough holes and the ship starts taking water, leans to one side and eventually goes under. houses fall down too if you hit them hard enough (sorry venice)

made on S.T.R.AC.E, my own engine (D3D11, windows only for now)

## controls

- **W / S** or up/down arrows - speed up / slow down
- **A / D** or left/right arrows - steer
- **mouse** - you can also just use the console at the bottom (lever, wheel, horn, camera, pause)
- **scroll** - zoom
- **H** - horn. very important
- **C** - toggle follow camera
- **R** - restart
- **P / Esc** - pause

## running it

open `Shipfulness.strproj` from the S.T.R.AC.E hub. the engine isn't in this repo, so you'll need it separately.

- hit Play in the editor to test. the scripts in `Assets/Scripts/` compile on their own when you do
- to make the actual game go to Build Settings and hit build. it ends up in `Build/Windows/` (the exe, `EngineCore.dll`, `Scripts.dll` and `Shipfulness.pak`). zip that whole folder if you want to send it to someone

`Build/` and `Intermediate/` get generated by the engine so they're not in the repo

## where stuff is

```
Assets/Scripts/      the game itself, in C++. ShipfulnessGame.cpp is where it starts
  ShipSim.h          how the ship moves and bumps into things
  HullDamage.h       the hull breaking, the collision that follows it, hull %
  SceneLink.h        levels, houses, obstacles, wakes
  FillLayer.h        the city that gets generated around the canal
  Console3D.h        the 3d control console
  AudioDirector.h    sound
Assets/Shaders/      water, hull, houses, wake, effects, post
Assets/Modelos/      meshes (.strmesh) + the original .fbx files
Scenes/Main.strscene
```
